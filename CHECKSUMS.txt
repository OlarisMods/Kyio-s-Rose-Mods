ROSE cosmetic packs - SHA-256 checksums
======================================================================

Verify a download before installing it. On Windows, open PowerShell in the
folder you downloaded to and run:

    Get-FileHash .\FILENAME.zip -Algorithm SHA256

Compare the result to the value below. If it matches, the file is byte-for-byte
what I published. If it does not, do not install it - tell me.

WHAT IS INSIDE

Every pack contains only these file types:
    .dds   texture images
    .zms   mesh geometry (the beam and drop shapes)
    .cur   mouse cursors
    .css   stylesheets (plain text - open them and read them)
    .html  interface layout (plain text - same)
    .json  a manifest describing the pack (plain text - same)
    .txt   readme and file list

There is no installer, no .exe, no .dll, no script of any kind. Nothing in
these archives can execute. Installing is copying files into a folder, and
uninstalling is deleting them.
