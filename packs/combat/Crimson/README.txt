====================================================================
  CRIMSON -- COMBAT TEXT ONLY for ROSE Online
====================================================================

WHAT THIS IS
Just the floating combat numbers from the Crimson UI theme, on their own,
for anyone who wants the damage readout without changing their whole
interface.

Client-side, cosmetic, fully reversible. 13 files, nothing else.

--------------------------------------------------------------------
HOW TO INSTALL
--------------------------------------------------------------------
1. Close ROSE completely.
2. (Recommended) Back up <ROSE>\3ddata\EFFECT.
3. Copy the '3ddata' folder from this pack into your ROSE Online
   install folder, letting it merge.
      Typical location: C:\Program Files\ROSE Online
4. Start the game.

If you already run the full Crimson UI theme, you do NOT need this -- the
combat text is already included in it.

--------------------------------------------------------------------
THE COLOUR SCHEME
--------------------------------------------------------------------
Damage types are told apart by COLOUR, so each one is assigned rather
than everything being tinted the same way:

  damage you deal      theme colour
  damage you take      red        (the same red in every theme, on
                                   purpose -- so it always reads the
                                   same way no matter what you run)
  healing              green      (likewise pinned)
  critical hits        matches the theme's glow
  blocked / absorbed   muted variants
  miss                 neutral grey

In Crimson, Moldie and Ancient, received-red and heal-green are IDENTICAL
- they never change between themes, because being able to tell a hit from
a heal at a glance matters more than matching the palette.

VOID IS THE EXCEPTION. It was made before I settled on that rule, so its
whole set sits in the violet/magenta family - its healing reads blue and
its received damage reads magenta. It looks great with the Void UI, but
if you want the clearest possible readout, one of the other three is the
better pick.

--------------------------------------------------------------------
HOW TO UNINSTALL
--------------------------------------------------------------------
Delete the files you copied in. That's the whole process.

ROSE loads loose files on disk in preference to its packed archives, so
copying these in does not modify or replace any original game data --
it just sits on top of it. Remove them and the client falls straight
back to the stock art. FILE_LIST.txt in this folder lists every file
this pack installs, so you always know exactly what to delete.

Nothing here touches the server, your account, or any game logic. It is
cosmetic and client-side only.

--------------------------------------------------------------------
NOTES
--------------------------------------------------------------------
* Nothing you install here can be left behind. The original artwork lives
  inside the game's own packed archives and is never modified -- deleting
  the files in FILE_LIST.txt is a complete return to stock.
* Some windows cache their artwork. If part of the UI still looks
  unchanged, close and reopen that window, or restart the client.
* All artwork here is original work, produced by recolouring my own
  Void set. No third-party assets are included and no game files are
  redistributed.
