====================================================================
  VERDIGRIS -- DOUBLE SIZE loot beam set for ROSE Online
  every drop group, twice as large
====================================================================

WHAT THIS IS
The complete Verdigris loot beam set with every model scaled to 200%.
Same shapes, same colors, same textures -- just twice the size, so
drops are visible from further away.

Made for anyone who finds the normal size hard to see. If you want the
standard size, the normal Verdigris packs are on the same page; they use
the same filenames, so installing one over the other swaps them cleanly.

--------------------------------------------------------------------
HOW TO INSTALL
--------------------------------------------------------------------
1. Close ROSE completely.
2. Copy the '3ddata' folder from this pack into your ROSE Online
   install folder, letting it merge.
      Typical location: C:\Program Files\ROSE Online
3. Start the game.

--------------------------------------------------------------------
HOW TO UNINSTALL
--------------------------------------------------------------------
Delete the files listed in FILE_LIST.txt. That's the whole process.

ROSE loads loose files on disk in preference to its packed archives, so
this does not modify or replace any original game data -- it sits on top
of it, and removing it falls straight back to stock.

--------------------------------------------------------------------
NOTES
--------------------------------------------------------------------
* At double size the textures are stretched over four times the area,
  so fine detail is a little softer up close. Shapes and beams are
  unaffected.
* The beams are twice as tall as well.
* All artwork here is original work. Nothing in this archive can execute.
