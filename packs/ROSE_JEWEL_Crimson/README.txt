====================================================================
  CRIMSON -- ACCESSORY loot beam for ROSE Online
  red
====================================================================

WHAT THIS IS
A replacement drop model for rings, necklaces and earrings -- a band
set with a stone, on a small plinth, with a beam of light above it.

All three accessory types share one model in the game already, so they
share this one too. Three files: two meshes and one texture they both
use.

The beam is pixel-identical to my other loot beams of the same color,
so the whole collection reads as one set.

Client-side, cosmetic, fully reversible. Works with any UI theme, or
with none.

--------------------------------------------------------------------
HOW TO INSTALL
--------------------------------------------------------------------
1. Close ROSE completely.
2. (Recommended) Back up <ROSE>\3ddata\item\common.
3. Copy the '3ddata' folder from this pack into your ROSE Online
   install folder, letting it merge.
      Typical location: C:\Program Files\ROSE Online
4. Start the game.

Only one color at a time. To switch, install another over the top.

--------------------------------------------------------------------
HOW TO UNINSTALL
--------------------------------------------------------------------
Delete the files listed in FILE_LIST.txt. That's the whole process.

ROSE loads loose files on disk in preference to its packed archives, so
this does not modify or replace any original game data -- it sits on top
of it, and removing it falls straight back to stock.

--------------------------------------------------------------------
NOTES
--------------------------------------------------------------------
* 'common' also holds a few other drop models. This pack touches only
  the three files listed in FILE_LIST.txt and nothing else in there.
* The texture is called necklace01.dds and is used by the ring too.
  That is what the game asks for -- don't rename it.
* All artwork here is original work. No third-party assets are included
  and no game files are redistributed.
* Nothing in this archive can execute.
