====================================================================
  VOID -- COMBAT TEXT, LARGE
  violet
====================================================================

WHAT THIS IS
The Void combat text with the numbers drawn as large as the game allows
-- about 36% taller than stock.

The original artwork leaves roughly a third of each number's space
empty, so at any distance you are reading smaller digits than you need
to be. This fills that space. Same colors, same behaviour, same
everything else -- just legible.

Received-red and heal-green stay pinned exactly as in the normal pack.

--------------------------------------------------------------------
WHY 36% AND NOT DOUBLE
--------------------------------------------------------------------
The size the game draws these at lives in the effect definition, which
is encrypted and not something a mod can reach. The artwork is what CAN
be changed, and this uses all of it: the numbers now run nearly the full
height of their cell and stop one pixel short on each side. Any wider
and neighbouring digits run into each other.

--------------------------------------------------------------------
HOW TO INSTALL
--------------------------------------------------------------------
1. Close ROSE completely.
2. (Recommended) Back up <ROSE>\3ddata\EFFECT.
3. Copy the '3ddata' folder from this pack into your ROSE Online
   install folder, letting it merge.
      Typical location: C:\Program Files\ROSE Online
4. Start the game.

Install over the normal Void combat text to swap -- same filenames.

--------------------------------------------------------------------
HOW TO UNINSTALL
--------------------------------------------------------------------
Delete the files listed in FILE_LIST.txt. That's the whole process.

ROSE loads loose files on disk in preference to its packed archives, so
this does not modify or replace any original game data.

Nothing in this archive can execute.
