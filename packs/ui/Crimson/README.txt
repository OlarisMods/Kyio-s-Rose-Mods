====================================================================
  CRIMSON -- UI THEME for ROSE Online
  near-black glass, blood-red glow, bone-white rim, amber alerts
====================================================================

WHAT THIS IS
A full cosmetic recolour of the game interface: window frames, buttons,
tabs, the chat box, the minimap ring, cursors, the HP/MP/EXP gauges,
and the floating combat numbers.

Client-side, cosmetic, and fully reversible. No server-side anything.

--------------------------------------------------------------------
HOW TO INSTALL
--------------------------------------------------------------------
1. Close ROSE completely.

2. (Recommended) Back up the folders you're about to write into:
      <ROSE>\3ddata\control\Res
      <ROSE>\data\ui\themes\rose
      <ROSE>\res
   Copying the whole folders somewhere safe is plenty.

3. Copy the '3ddata', 'data' and 'res' folders from this pack into
   your ROSE Online install folder, letting them merge.

   Typical location:
      C:\Program Files\ROSE Online

   Windows will ask you to confirm replacing files -- that's expected.
   You may need to accept an administrator prompt.

4. Start the game.

Only ONE UI theme can be installed at a time. To switch themes, install
another one straight over the top -- every theme ships the same file
list, so nothing gets left behind.

--------------------------------------------------------------------
WHAT'S IN THE BOX
--------------------------------------------------------------------
* Window frames, panels, buttons, tabs, dropdowns, edit boxes
* Chat box colours, minimap ring, scrollbars
* 19 mouse cursors
* HP / MP / EXP / PAT-fuel gauges
* Floating combat numbers + the CRIT graphic

Deliberately NOT included:
* Potion / loot-beam colours -- those are a separate download, so you
  can mix and match rather than having a colour forced on you.
* Fonts, particle effects, nameplate health bars, character-sheet stat
  numbers. These are engine-side and can't be changed from a mod.

--------------------------------------------------------------------
HOW TO UNINSTALL
--------------------------------------------------------------------
Delete the files you copied in. That's the whole process.

ROSE loads loose files on disk in preference to its packed archives, so
copying these in does not modify or replace any original game data --
it just sits on top of it. Remove them and the client falls straight
back to the stock art. FILE_LIST.txt in this folder lists every file
this pack installs, so you always know exactly what to delete.

Nothing here touches the server, your account, or any game logic. It is
cosmetic and client-side only.

--------------------------------------------------------------------
NOTES
--------------------------------------------------------------------
* Nothing you install here can be left behind. The original artwork lives
  inside the game's own packed archives and is never modified -- deleting
  the files in FILE_LIST.txt is a complete return to stock.
* Some windows cache their artwork. If part of the UI still looks
  unchanged, close and reopen that window, or restart the client.
* All artwork here is original work, produced by recolouring my own
  Void set. No third-party assets are included and no game files are
  redistributed.
