====================================================================
  RUNE -- ZODIAC & RUNE STONE loot beam for ROSE Online
  deep green
====================================================================

WHAT THIS IS
A replacement drop model for the Dirty Zodiac Stone and Dirty Rune Stone -- a carved standing
stone with a glowing rune, and the vertical light beam above it.

Two files: the texture, and the mesh. The mesh is my own work, built
from scratch, and the beam will not render without it -- so install
both.

The beam itself is pixel-identical to my potion beams of the same
colour, so the whole collection reads as one set.

Client-side, cosmetic, fully reversible. Works with any UI theme, or
with none.

--------------------------------------------------------------------
HOW TO INSTALL
--------------------------------------------------------------------
1. Close ROSE completely.
2. (Recommended) Back up <ROSE>\3ddata\item\di22.
3. Copy the '3ddata' folder from this pack into your ROSE Online
   install folder, letting it merge.
      Typical location: C:\Program Files\ROSE Online
4. Start the game.

Only one colour at a time per category. To switch, install another
straight over the top. Different categories are independent -- mix and
match freely.

--------------------------------------------------------------------
HOW TO UNINSTALL
--------------------------------------------------------------------
Delete the files you copied in. That's the whole process.

ROSE loads loose files on disk in preference to its packed archives, so
copying these in does not modify or replace any original game data --
it just sits on top of it. Remove them and the client falls straight
back to the stock art. FILE_LIST.txt in this folder lists every file
this pack installs, so you always know exactly what to delete.

Nothing here touches the server, your account, or any game logic. It is
cosmetic and client-side only.

--------------------------------------------------------------------
NOTES
--------------------------------------------------------------------
* The mesh filename is 'd22.zms', not 'di22.zms'. That is correct --
  the game asks for it by that name. Don't rename it.
* Nothing you install here can be left behind. The original artwork lives
  inside the game's own packed archives and is never modified -- deleting
  the files in FILE_LIST.txt is a complete return to stock.
* All artwork here is original work. No third-party assets are included
  and no game files are redistributed.
