====================================================================
  COMMUNITY WINDOW -- ROSE Online UI mod by Kyio
====================================================================

WHAT THIS IS
Your Friends window, with three extra tabs added.

  Friends    the game's own friend list, unchanged
  Ignore     the game's own ignore list, unchanged
  Notes      a notepad you can type in
  Checklist  eight tick-boxes with a quantity and a label each
  Symbols    emoji you can copy and paste into chat

Notes and Checklist keep whatever you type for as long as the client
is running -- you can close the window, reopen it, and it is still
there. It is NOT saved to disk. Everything clears when you close the
game.

The Notes tab also shows your zone, coordinates and server time.

--------------------------------------------------------------------
HOW TO INSTALL
--------------------------------------------------------------------
1. Close ROSE completely.
2. Copy the 'data' folder from this pack into your ROSE Online
   install folder, letting it merge.
      Typical location: C:\Program Files\ROSE Online
3. Start the game. Open your Friends window as usual.

The window is wider than the original to fit the tabs. You can resize
it, and it remembers nothing between sessions.

--------------------------------------------------------------------
HOW TO UNINSTALL
--------------------------------------------------------------------
Delete the file listed in FILE_LIST.txt. That's the whole process.

ROSE loads loose files on disk in preference to its packed archives,
so this does not modify or replace any original game data -- it sits
on top of it, and removing it falls straight back to stock.

NOTES
