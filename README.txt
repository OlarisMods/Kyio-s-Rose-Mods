VOID HALLOWEEN -- media for the repo
====================================
Optimised for GitHub: 15 fps, 640px wide (720 for the crit), full 256-colour
palettes, light compression. Checked frame by frame against the originals --
no visible loss. The set went from 244 MB to about 55.

    01_buffs           all nine buffs, a gif and a still each, plus allbuffs
    02_combat_text     the crit, and the damage numbers and words, rendered
                       straight from the pack's own textures
    03_cauldrons       all six drop colours
    04_summons         the haunted summons
    05_state_icons     the class buff icons, and the party window
    06_summon_gauge    resting, full (no slots), low HP, out of range
    07_minimap         the tombstone frame
    ui                 the whole interface

KEEP YOUR ORIGINALS. These are for the repo; the full-resolution captures are
worth keeping off it, since git keeps every version of a file forever.
